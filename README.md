# «Поколение» — школьное приложение

**Версия: 0.2.0 (build 2)**

Flutter-приложение для школьной навигации, расписания, дополнительных занятий и школьных уведомлений. Основная карта и расписание доступны офлайн; серверные возможности включаются отдельно после настройки адреса API и инфраструктуры школы.

## Возможности приложения

- Интерактивные планы 1-го, 2-го и 3-го этажей.
- Поиск кабинетов по номеру и названию.
- Построение маршрута между кабинетами и специальными помещениями, пошаговые подсказки и линия маршрута на плане.
- Масштабирование, панорамирование, полноэкранная карта и адаптация интерфейса.
- Локальное расписание и расписание по классам с выбором учебных групп.
- Раздел дополнительных занятий (ДОПы), маршрут до кабинета занятия и локальные напоминания при наличии реального времени начала.
- Объявления и школьные оповещения с офлайн-кешем.
- «Кабинет школы» с разграничением прав для учеников и сотрудников.
- Школьная авторизация через OIDC Authorization Code + PKCE; защищённое хранение мобильных токенов.
- Серверные аккаунты, назначения наставников и учителей, управление ДОПами, журнал аудита и необязательные push-уведомления Firebase Cloud Messaging.
- Основные планы этажей и данные навигации включены в приложение, поэтому маршрутизация не требует интернета.

## Структура

| Путь | Назначение |
|---|---|
| `lib/main.dart` | Основной экран, расписание, каталог помещений и движок маршрутизации |
| `lib/school_portal_page.dart` | Интерфейс школьного портала |
| `lib/school_account_service.dart` | Вход, сессии, защищённое хранение токенов и push-регистрация |

| `test/`, `backend/tests/` | Автоматические проверки Flutter и сервера |
| `docs/` | Инструкция по серверу, безопасность, аудит навигации и заметки о выпуске |

## Запуск Flutter

Требуется Flutter stable, версия SDK указана в `pubspec.yaml`. Для Android-сборки нужны Android SDK и JDK 21.

```powershell
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

APK после успешной локальной сборки появится в `build/app/outputs/flutter-apk/app-release.apk`. Номер версии Android берётся из поля `version` в `pubspec.yaml` — сейчас `0.2.0+2` (версия приложения 0.2.0, build number 2).

## Сервер (необязателен для офлайн-карты)

Сервер работает на FastAPI. Для основных публичных справочников он получает данные из одного из двух настраиваемых источников: локального JSON-файла или HTTPS API. Явная настройка источника задаётся переменной `NAVIGATOR_DATA_SOURCE` (`json` или `http`). Никаких облачных провайдеров или OAuth-токенов для файлового хранилища в коде не требуется.

1. Скопируй `.env.example` в `.env` и задай секреты только на сервере.
2. Подготовь JSON-источник: объект с коллекциями `Classes`, `BaseSchedule`, `Rooms`, `Places`, `Announcements` и при необходимости `Supplements`; каждая коллекция — массив объектов.
3. Укажи `NAVIGATOR_DATA_JSON_PATH` либо настрой `NAVIGATOR_DATA_API_URL` и необязательный `NAVIGATOR_DATA_API_TOKEN`.
4. Настрой школьный OIDC-провайдер, если нужен вход сотрудников и учеников. Настройки должен подтвердить школьный IT-администратор.
5. Для push-уведомлений отдельно настрой проект Firebase; service-account credentials храни только в окружении сервера.

Пример запуска сервера в Docker и перечень переменных находится в [документации серверной интеграции](docs/SERVER_INTEGRATION.md). На сервере требуется HTTPS reverse proxy; Docker Compose публикует API только на loopback-интерфейсе.

## Тесты и безопасность

```powershell
python -m pip install -r backend/requirements.txt
python -m pip install -r backend/requirements-firebase.txt  # только для push-уведомлений
python backend/security_check.py
python -m unittest discover -s backend/tests -v
flutter test
flutter analyze --no-fatal-infos --no-fatal-warnings
```

Локальные проверки прав в APK не заменяют серверную авторизацию. Не размещай в репозитории пароли, токены, `.env`, приватные ключи подписи или Firebase service-account JSON. Не используй приложение как единственный канал экстренного оповещения.

Геометрия маршрутов проверяется автотестами, однако это не заверенная схема эвакуации. Перед реальным ориентированием нужно сопоставить все маршруты с утверждёнными планами и проверить их с ответственным сотрудником школы.
