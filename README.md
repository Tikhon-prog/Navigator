# Navigator — школа «Поколение»

Офлайн-приложение на Flutter для навигации по школе.

## Реализовано

- карта 1, 2 и 3 этажей;
- поиск кабинета **по всем этажам**;
- карточка кабинета и выбор кабинета;
- построение маршрута от выбранной точки старта;
- офлайн-граф коридоров и лестниц + Dijkstra;
- пошаговые инструкции маршрута;
- визуальная линия маршрута на плане этажа;
- полноэкранная карта;
- масштабирование и панорамирование;
- адаптация для телефонов, планшетов и горизонтального режима;
- три цветовые темы;
- имя пользователя с сохранением на устройстве;
- локальное редактируемое расписание без сервера;
- исходный PDF с планами школы хранится внутри APK для полного офлайн-пакета;
- никаких сетевых карт, Firebase или обязательного интернет-сервера.

## Запуск

```text
flutter pub get
flutter analyze
flutter build apk --release
```

Для установки на телефон используй файл release APK из `build/app/outputs/flutter-apk/`.

## Важно о размере APK

Размер APK сам по себе не является показателем количества функций. Flutter release APK содержит движок и ресурсы, но его размер зависит от ABI и сжатия. Этот проект содержит исходный PDF и карты в высоком разрешении как реальные офлайн-данные, но намеренно не добавляет бесполезный мусор только ради достижения произвольного размера файла.

## Навигационные данные

Координаты кабинетов и граф маршрутов находятся локально. Если появится официальная уточнённая схема коридоров/лестниц, её можно заменить без подключения к серверу.

## Navigator 1.0.0

Основа офлайн-навигатора школы «Поколение».

### Навигация
- маршрут от главного входа;
- маршрут от выбранного этажа;
- маршрут **от любого кабинета/места до любого другого кабинета/места**;
- Dijkstra по локальному графу коридоров и лестниц;
- переходы между этажами;
- визуальный маршрут на планах;
- пошаговые инструкции.

### Поиск
Поиск выполняется по всем этажам и включает как 90 пронумерованных помещений из легенд планов, так и отдельные специализированные пространства, например столовую, бассейн, спортивный зал, террасу и информационно-библиотечный центр.

### Дополнительные занятия
Раздел для ДОПов намеренно не заполнен выдуманными данными. После получения от пользователя реального списка занятий и кабинетов его можно подключить к той же системе точек назначения и маршрутов.

### Navigation data
- `assets/data/door_points.json` contains normalized door-threshold anchors for all rooms and special places.
- `assets/maps/floor1_doors_debug.png`, `floor2_doors_debug.png`, `floor3_doors_debug.png` are visual review maps for the navigation anchors.
- The staircase near the sleeping-corpus passage is intentionally not connected to floor 3; the main staircase by the purple wing is used for 2<->3 routing.

Документация API, роли наставников/учителей, доступ к ДОПам, уведомления Firebase и переменные окружения: [docs/SERVER_INTEGRATION.md](docs/SERVER_INTEGRATION.md).
