# Поколение — школьное приложение

Офлайн-приложение на Flutter для навигации по школе.

## Реализовано

- карта 1, 2 и 3 этажей;
- поиск кабинета **по всем этажам**;
- карточка кабинета и выбор кабинета;
- построение маршрута от выбранной точки старта;
- офлайн-граф коридоров и лестниц + A* с приоритетом маршрутов без смены этажа;
- пошаговые инструкции маршрута;
- визуальная линия маршрута на плане этажа;
- полноэкранная карта;
- масштабирование и панорамирование;
- адаптация для телефонов, планшетов и горизонтального режима;
- три цветовые темы;
- имя пользователя и выбранный класс сохраняются на устройстве;
- локальное редактируемое расписание и выбор учебных групп; при настроенном сервере расписание может обновляться из `BaseSchedule`, сохраняя офлайн-кеш;
- раздел «Объявления и оповещения»: общие, целевые и персональные сообщения из настроенного API, фильтрация по классу, безопасный пользовательский кеш и офлайн-просмотр;
- локальные напоминания о ДОПах за 15 минут до занятия, если указано реальное время в формате ЧЧ:ММ;
- школьный SSO через OIDC Authorization Code + PKCE и ограниченный технический вход администратора для первоначальной настройки;
- ролевой «Кабинет школы»: директор, завуч, классный руководитель, учитель-предметник, наставник, координаторы ДОПов/наставников, библиотекарь и администратор;
- управление аккаунтами и должностями, назначение наставников/учителей ученикам, просмотр ДОПов с проверкой прав, импорт из источника данных, журнал аудита;
- Firebase Cloud Messaging для общих, целевых, персональных и экстренных уведомлений; серверные напоминания о ДОПах с пользовательским согласием;
- исходный PDF с планами школы хранится внутри APK для полного офлайн-пакета;
- карта остаётся офлайн; для серверных функций требуются настроенный адрес API, школьный IdP, источник данных и Firebase-проект.

## Запуск

```text
flutter pub get
flutter analyze
flutter build apk --release
```

Для установки на телефон используй файл release APK из `build/app/outputs/flutter-apk/`.

## Важно о размере APK

Размер APK сам по себе не является показателем количества функций. Flutter release APK содержит движок и ресурсы, но его размер зависит от ABI и сжатия. Этот проект содержит исходный PDF и карты в высоком разрешении как реальные офлайн-данные, но намеренно не добавляет бесполезный мусор только ради достижения произвольного размера файла.

## Навигационные данные

Координаты кабинетов и граф маршрутов находятся локально. Построение маршрута и пошаговые инструкции работают без сервера; выбор этажа для просмотра не меняет фактическую точку старта. Автотесты проверяют связность маршрутов, отсутствие длинных коллинеарных дубликатов и переходы между этажами. Это не заменяет визуальную сверку каждого коридора с утверждённым планом школы: перед использованием для реального ориентирования/эвакуации необходимо проверить геометрию с ответственным сотрудником школы.

## Поколение 1.0.0

Основа офлайн-навигатора школы «Поколение».

### Навигация
- маршрут от главного входа;
- маршрут от главного входа или от выбранного кабинета/места; выбор этажа для просмотра карты не подменяет точку старта;
- маршрут **от любого кабинета/места до любого другого кабинета/места**;
- A* по локальному графу коридоров и лестниц с реальной геометрией карты;
- переходы между этажами;
- визуальный маршрут на планах;
- пошаговые инструкции.

### Поиск
Поиск выполняется по всем этажам и включает как 90 пронумерованных помещений из легенд планов, так и отдельные специализированные пространства, например столовую, бассейн, спортивный зал, террасу и информационно-библиотечный центр.

### Дополнительные занятия
Раздел ДОПов хранит локальные записи, может импортировать данные из школьного intranet и строит маршрут до указанного кабинета. Напоминания на устройстве работают только для записей с настоящим временем начала; импортированные номера уроков не считаются часами автоматически.

### Navigation data
- `assets/data/door_points.json` contains normalized door-threshold anchors for all rooms and special places.
- `assets/maps/floor1_doors_debug.png`, `floor2_doors_debug.png`, `floor3_doors_debug.png` are visual review maps for the navigation anchors.
- The staircase near the sleeping-corpus passage is intentionally not connected to floor 3; the main staircase by the purple wing is used for 2<->3 routing.


## Серверная интеграция (ветка подготовки)

Документация API, роли наставников/учителей, доступ к ДОПам, уведомления Firebase и переменные окружения: [docs/SERVER_INTEGRATION.md](docs/SERVER_INTEGRATION.md). Серверная часть подключена отдельным пространством маршрутов `/api/v2`; для реального запуска требуются серверные секреты и согласованная школой модель данных.
