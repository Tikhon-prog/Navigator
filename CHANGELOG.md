# История изменений

## 0.2.0 — 18 октября 2026

- Подготовлена версия приложения 0.2.0 (Android build number 2).
- Добавлен ролевой школьный портал и расширена серверная API-интеграция.
- Усилена авторизация: OIDC Authorization Code + PKCE, защищённое хранение мобильных токенов, ротация refresh-токенов и отзыв сессий.
- Добавлены серверные сущности учётных записей, связей ученик–наставник/учитель, индивидуальных ДОПов, устройств, уведомлений и аудита.
- Подготовлены JSON/HTTPS адаптеры источников данных; устаревший облачный файловый и табличный backend удалён.
- Добавлены проверки ролей, синхронизации, объявлений, геометрии маршрутов и потенциальных секретов.
- Документация сборки, развертывания, безопасности и конфигурации обновлена под 0.2.0.

### Известные ограничения

- Для серверных функций нужны согласованные школьные настройки SSO, источник данных и, если нужен push, Firebase.
- Геометрия навигации требует проверки с утверждёнными планами; автотесты связности не сертифицируют эвакуационные маршруты.
- Перед подключением настоящих данных учеников необходимы согласование с администрацией школы и проверка инфраструктуры.
- Выпускной APK считается готовым только после успешной Android release-сборки и проверки артефакта.
