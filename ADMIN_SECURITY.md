# Navigator — усиленные полномочия администраторов

## Роли
- **Главный администратор** — полный доступ.
- **Администратор** — данные, расписание, объявления, кабинеты/места, API и аудит.
- **Контент-администратор** — данные, расписание, объявления, кабинеты/места и просмотр аудита.

## Защита
- Каждое административное действие проверяет permission текущего аккаунта.
- После 5 неверных входов аккаунт логина блокируется на 5 минут.
- Новые пароли хранятся как `v2` с уникальной солью и 40 000 итерациями SHA-256.
- Старые SHA-256 автоматически мигрируют на новый формат после успешного входа.
- Ведётся локальный журнал последних 300 административных событий.
- Можно отключать, редактировать и удалять администраторов (root удалить нельзя).

## Важно
Это усиление локального режима. Оно не превращает APK в доверенный сервер: пользователь с полным доступом к устройству/данным приложения потенциально может изменить локальное хранилище. Для настоящего разграничения полномочий сервер должен повторно проверять роль и права каждого API-запроса.
