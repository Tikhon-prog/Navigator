# Navigator — усиленные полномочия администраторов

## Роли
- Главный администратор — полный доступ.
- Администратор — данные, расписание, объявления, кабинеты/места, API и аудит.
- Контент-администратор — данные, расписание, объявления, кабинеты/места и просмотр аудита.

## Защита
- Каждое административное действие проверяет permission текущего аккаунта.
- После 5 неверных входов аккаунт блокируется на 5 минут.
- Новые пароли используют уникальную соль и повторное хеширование SHA-256.
- Старые SHA-256 могут мигрировать на новый формат после успешного входа.
- Локальный журнал последних административных событий.
- root нельзя удалить или отключить.

Локальная защита не заменяет серверную авторизацию: пользователь с полным доступом к устройству потенциально может изменить данные APK.
