# Navigator_Master.xlsx

Это схема облачных данных Navigator. Сам XLSX-шаблон находится рядом с этим README.

Листы:
- Admins — администраторы; пароль хранится только как SHA-256.
- Classes — классы и их настройки.
- BaseSchedule — базовое расписание класса, которое является источником истины для ученика.
- Supplements — расширенные ДОПы: не только корпус, но и место, учитель, время, группа, описание и маршрут.
- Rooms — кабинеты и служебные помещения.
- Places — столовая, бассейн, медпункт, тренажёрный зал, хореография, мастерские и т. д.
- Announcements — объявления.
- Devices — push-токены устройств и подписки класса.
- AuditLog — журнал действий администраторов.
- Settings — параметры API и версии данных.

Важное правило расписания: последний успешно синхронизированный снимок не заменяет базовое расписание. Клиент сначала использует расписание своего класса, сохранённое локально/введённое учеником или классным руководителем, а серверная синхронизация обновляет именно базовый набор при наличии новой версии.
