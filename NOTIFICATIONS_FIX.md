# Уведомления Navigator

- планирование уведомлений на 7 календарных дней;
- очистка старых уведомлений перед повторным планированием;
- отдельный Android notification channel;
- POST_NOTIFICATIONS на Android 13+;
- Europe/Moscow для времени школы;
- Android receivers для восстановления после перезагрузки;
- синхронизация расписания перепланирует уведомления;
- напоминание за 5 минут до урока.
