# История изменений

## Локальный ИИ и персональные настройки

- Добавлена отдельная загрузка Qwen2.5-0.5B-Instruct Q4_K_M (~398 МБ); модель не включается в APK и запускается офлайн через `llm_llamacpp`.
- Добавлены проверки размера, заголовка GGUF и SHA-256 до активации скачанного файла.
- Добавлено изменение названий математических уроков естественным языком; недостающие слоты уточняются, изменения сохраняются только после подтверждения.
- Добавлены локальные предпочтения обхода кабинетов с мягким штрафом в графе реальных коридоров; рёбра графа не удаляются.
- Добавлено сохранение замечаний к маршрутам для последующего аудита без автоматического изменения геометрии школы.
- Добавлен фильтр помещений по типу и новые регрессионные тесты.


## 0.2.0+2 — перемены и заметки

- Добавлен секундный обратный отсчёт до конца урока и до следующего урока во время перемены; время берётся из расписания выбранного класса.
- Добавлены личные заметки: создание, редактирование, удаление и локальное сохранение без отправки на сервер.


## 0.2.0+2 — мультиплатформенная сборка и Windows

- Разделены проверка качества и независимые задачи release-сборки Android APK и Windows installer EXE.
- Добавлен Inno Setup installer, включающий Windows EXE, Flutter runtime DLL и файлы приложения.
- Добавлен Windows-вход в школьный OIDC через системный браузер и Authorization Code + PKCE с loopback callback.
- Включена Windows-инициализация локальных уведомлений и опрос ленты школьных оповещений, пока desktop-приложение запущено.
- Сборка не вызывает Android Edge-to-Edge API и Firebase Messaging на Windows; Android-поведение сохранено.
- Обновлены инструкции по сборке, настройке OIDC, API, runner и требованиям к Microsoft C++/ATL.

## 0.2.0 — 18 октября 2026

- Подготовлена версия приложения 0.2.0 (Android build number 2).
- Добавлен ролевой школьный портал и расширена серверная API-интеграция.
- Усилена авторизация: OIDC Authorization Code + PKCE, защищённое хранение мобильных токенов, ротация refresh-токенов и отзыв сессий.
- Добавлены серверные сущности учётных записей, связей ученик–наставник/учитель, индивидуальных ДОПов, устройств, уведомлений и аудита.
- Подготовлены JSON/HTTPS адаптеры источников данных; устаревший облачный файловый и табличный backend удалён.
- Добавлены проверки ролей, синхронизации, объявлений, геометрии маршрутов и потенциальных секретов.
- Реализован bootstrap первого директора через серверную конфигурацию, с необязательной привязкой к подтверждённому SSO subject.
- Директор и завуч могут просматривать журнал общешкольных рассылок и отменять ожидающую доставку; добавлены серверные проверки прав и регрессионные тесты.
- В клиенте исправлено использование сохранённого адреса API после школьного входа, чтобы авторизованная лента уведомлений была доступна в разделе «Оповещения».
- Пользовательские названия клиента, web-приложения и Windows-сборки приведены к бренду «Поколение»; внутренние ID пакета и Android deep-link scheme сохранены для совместимости.
- Документация сборки, развертывания, безопасности и конфигурации обновлена под 0.2.0.

### Известные ограничения

- Для серверных функций нужны согласованные школьные настройки SSO, источник данных и, если нужен push, Firebase.
- Геометрия навигации требует проверки с утверждёнными планами; автотесты связности не сертифицируют эвакуационные маршруты.
- Перед подключением настоящих данных учеников необходимы согласование с администрацией школы и проверка инфраструктуры.
- Выпускной APK считается готовым только после успешной Android release-сборки и проверки артефакта.
