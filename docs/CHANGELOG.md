# История изменений

## 0.2.2+8 — уведомления, голосования, «Все функции»

- Уведомления: цвет и подпись по типу (школа — красный, класс — зелёный, лично — синий, экстренное — бордовый), закреплённые на Android, отдельный канал для сообщений класса.
- Голосования школы и класса (сервер `/api/v2/polls`, экран «Голосования»); создают сотрудники, итоги видны после голоса.
- Раздел «Все функции» с категориями и поиском.
- Экран наставников: расписание класса подопечного.
- Удалена функция «Домашние задания».
- Шрифт Inter, единые темы диалогов, нижних панелей и чипов; обновление объявлений жестом вниз.
- Безопасность: 5Б и 5В больше не считаются одним классом, ограничение попыток входа, выравнивание времени ответа при входе, проверка `state` в десктопном SSO, синхронизация класса из SSO, логин уникален без учёта регистра.
- Исправления: сортировка ДОПов по времени, стабильный id объявлений, защита от наложения запросов каталога, сопоставление преподавателя в парсере ДОПов, падение выбора старта на пустом этаже, устаревшие выпадающие списки, проверки mounted после диалогов.
- Код: `main.dart` разбит на части в `lib/src/`; backend переведён на lifespan; GitHub Actions не используются, сборка локальная.

## 0.2.1+7 — аудит надёжности и производительности

- Исправлена загрузка локальной GGUF-модели: приложение использует постоянный inference-isolate библиотеки и не создаёт вторую копию 491-МБ модели в главном isolate; ожидание ответа ограничено тайм-аутом.
- Домашние задания и настройки напоминаний изолированы по школьным аккаунтам; недействительная сессия не получает доступ к анонимному локальному профилю.
- Системные напоминания домашних заданий синхронизируются при входе, выходе и открытии раздела заданий.
- Некорректные дедлайны не превращаются в выдуманные даты.
- В расписании нормализуются время и номера уроков, онлайн-строки с некорректным временем пропускаются; группировка оптимизирована до линейного прохода.
- Секундный таймер расписания останавливается в скрытой вкладке и в фоне приложения.
- Backend безопасно сортирует строковые номера уроков; внешние data API и OIDC UserInfo не следуют редиректам с токенами.
- Ленты уведомлений и объявлений сначала фильтруют адресатов, затем применяют лимит; исправлены аудитории mentor/teacher и обзор администратора.
- CORS сервера закрыт по умолчанию и открывается только для явно настроенных школьных origin.
- Обновлены ABI-настройки сборки, версии iOS workflow, PWA hash navigation и справочные документы.
- Добавлены регрессионные тесты на время расписания, изоляцию аккаунтов, ленты уведомлений/объявлений и ограничения внешних запросов.

## 0.2.1+6 — расписание 8В и профили ДОПов

- Добавлено расписание 8В на 2 четверть по шести фотографиям; остальные 32 класса сохранены без изменений.
- Для 8В добавлен обязательный выбор общей подгруппы 8В/1 или 8В/2; общие уроки остаются видны обеим подгруппам.
- Сохранённая локальная версия расписания 8В защищена от перезаписи устаревшим кешем и онлайн-обновлением.
- Расписание ИИ-помощника и напоминания учитывают выбранную подгруппу.
- Для учеников 10-х классов добавлен обязательный выбор направления перед синхронизацией ДОПов; профиль сохраняется в настройках отдельного школьного аккаунта.
- Добавлены регрессионные тесты расписания, подгрупп 8В и профилей 10-х классов.


## 0.2.1+5 — аудит, надёжность данных и оптимизация

- Локальная модель использует `LlamaCppChatRepository.withModelPath()`: GGUF загружается в постоянном inference-isolate один раз, без второй копии модели в UI isolate.
- Домашние задания и настройки напоминаний разделены по школьным аккаунтам; старый офлайн-профиль остаётся отдельным и не переносится автоматически в другой аккаунт.
- ID уведомлений домашних заданий формируются с учётом профиля, а сохранённые наборы напоминаний разных профилей не смешиваются.
- Добавлены общие функции нормализации/сортировки времени; онлайн-расписание отбрасывает некорректные временные значения.
- Индекс выбора учебных групп рассчитывается один раз вместо повторного сканирования всего расписания для каждого урока.
- Секундный таймер расписания приостанавливается для скрытой вкладки и при сворачивании приложения.
- Тесты расширены проверками нормализации времени и разделения данных между аккаунтами.
- Сборочные скрипты Android ограничены ABI arm64-v8a и x86_64, для которых в поставке локального llama.cpp есть нативные библиотеки.

## 0.2.1+4 — интерфейс и локальный ИИ

- Исправлена подготовка Android CPU-бэкендов llama.cpp: приложение определяет каталог извлечённых нативных библиотек, загружает CPU-бэкенды до чтения GGUF-модели и проверяет регистрацию.
- Для Android включено извлечение нативных библиотек, необходимое динамическому поиску CPU-бэкендов.
- Ошибки запуска модели и загрузки больше не выводят пользователю технические пути и нативный стек; подробности остаются в диагностическом журнале.
- Убраны повторяющиеся плашки об офлайн-режиме и необходимости школьного intranet; экран объявлений стал компактнее.
- Добавлены плавные переходы между разделами и экранами, анимация появления сообщений в ИИ-чате и поддержка системной настройки уменьшения движения.
- Вместо системного окна «О приложении» добавлена отдельная страница с назначением и возможностями приложения для учеников и учителей школы «Поколение».

## 0.2.1+3 — отдельная PWA-версия для iPhone

- Документация сборки, развертывания, безопасности и конфигурации обновлена под 0.2.0.

### Известные ограничения

- Для серверных функций нужны согласованные школьные настройки SSO, источник данных и, если нужен push, Firebase.
- Геометрия навигации требует проверки с утверждёнными планами; автотесты связности не сертифицируют эвакуационные маршруты.
- Перед подключением настоящих данных учеников необходимы согласование с администрацией школы и проверка инфраструктуры.
- Выпускной APK считается готовым только после успешной Android release-сборки и проверки артефакта.
