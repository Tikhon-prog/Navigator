# История изменений

## 0.2.1+5 — аудит, надёжность данных и оптимизация

- Зависимость `llm_llamacpp` закреплена на 0.7.0; локальная модель загружается через штатный `BackendInitializer` и прямой `LlamaCppModel.load`, без старой цепочки `LlamaCppRepository.loadModel`.
- Домашние задания и настройки напоминаний разделены по школьным аккаунтам; старый офлайн-профиль остаётся отдельным и не переносится автоматически в другой аккаунт.
- ID уведомлений домашних заданий формируются с учётом профиля, а сохранённые наборы напоминаний разных профилей не смешиваются.
- Добавлены общие функции нормализации/сортировки времени; онлайн-расписание отбрасывает некорректные временные значения.
- Индекс выбора учебных групп рассчитывается один раз вместо повторного сканирования всего расписания для каждого урока.
- Секундный таймер расписания приостанавливается для скрытой вкладки и при сворачивании приложения.
- Тесты расширены проверками нормализации времени и разделения данных между аккаунтами.
- Сборочные скрипты Android ограничены ABI arm64-v8a и x86_64, для которых в поставке локального llama.cpp есть нативные библиотеки.

## 0.2.1+4 — интерфейс и локальный ИИ

- Исправлена подготовка Android CPU-бэкендов llama.cpp: приложение определяет каталог извлечённых нативных библиотек, загружает CPU-бэкенды до чтения GGUF-модели и проверяет регистрацию.
- Для Android включено извлечение нативных библиотек, необходимое динамическому поиску CPU-бэкендов.
- Ошибки запуска модели и загрузки больше не выводят пользователю технические пути и нативный стек; подробности остаются в диагностическом журнале.
- Убраны повторяющиеся плашки об офлайн-режиме и необходимости школьного intranet; экран объявлений стал компактнее.
- Добавлены плавные переходы между разделами и экранами, анимация появления сообщений в ИИ-чате и поддержка системной настройки уменьшения движения.
- Вместо системного окна «О приложении» добавлена отдельная страница с назначением и возможностями приложения для учеников и учителей школы «Поколение».

## 0.2.1+3 — отдельная PWA-версия для iPhone

- Версия Flutter-приложения повышена до 0.2.1 (build number 3).
- Добавлен отдельный каталог website/ с мобильной PWA-оболочкой на HTML, CSS и JavaScript для добавления на экран «Домой» iPhone.
- PWA использует собственные manifest, значок и service worker; каталог Flutter Web web/ не изменяется.
- Упрощён интерфейс PWA: убраны большой промобаннер, повторяющиеся карточки, технические предупреждения и декоративная псевдокарта.
- Компактнее оформлены главная, состояния расписания/карты/ДОПов/ИИ и установка на iPhone; добавлена поддержка возврата между разделами кнопкой «Назад» Safari.
- Обновлена тема PWA и версия кеша Service Worker для доставки нового интерфейса.
- Реальные школьные данные, ИИ-модель, push-отправка и база данных в PWA пока не подключены; для этого потребуется согласованный API и серверная часть.

# История изменений

## 0.2.0+2 — перемены и заметки

- Добавлен секундный обратный отсчёт до конца урока и до следующего урока во время перемены; время берётся из расписания выбранного класса.
- Добавлены личные заметки: создание, редактирование, удаление и локальное сохранение без отправки на сервер.


## 0.2.0+2 — мультиплатформенная сборка и Windows

- Разделены проверка качества и независимые задачи release-сборки Android APK и Windows installer EXE.
- Добавлен Inno Setup installer, включающий Windows EXE, Flutter runtime DLL и файлы приложения.
- Добавлен Windows-вход в школьный OIDC через системный браузер и Authorization Code + PKCE с loopback callback.
- Включена Windows-инициализация локальных уведомлений и опрос ленты школьных оповещений, пока desktop-приложение запущено.
- Сборка не вызывает Android Edge-to-Edge API и Firebase Messaging на Windows; Android-поведение сохранено.
- Обновлены инструкции по сборке, настройке OIDC, API, runner и требованиям к Microsoft C++/ATL.

## 0.2.0 — 18 октября 2026

- Подготовлена версия приложения 0.2.0 (Android build number 2).
- Добавлен ролевой школьный портал и расширена серверная API-интеграция.
- Усилена авторизация: OIDC Authorization Code + PKCE, защищённое хранение мобильных токенов, ротация refresh-токенов и отзыв сессий.
- Добавлены серверные сущности учётных записей, связей ученик–наставник/учитель, индивидуальных ДОПов, устройств, уведомлений и аудита.
- Подготовлены JSON/HTTPS адаптеры источников данных; устаревший облачный файловый и табличный backend удалён.
- Добавлены проверки ролей, синхронизации, объявлений, геометрии маршрутов и потенциальных секретов.
- Реализован bootstrap первого директора через серверную конфигурацию, с необязательной привязкой к подтверждённому SSO subject.
- Директор и завуч могут просматривать журнал общешкольных рассылок и отменять ожидающую доставку; добавлены серверные проверки прав и регрессионные тесты.
- В клиенте исправлено использование сохранённого адреса API после школьного входа, чтобы авторизованная лента уведомлений была доступна в разделе «Оповещения».
- Пользовательские названия клиента, web-приложения и Windows-сборки приведены к бренду «Поколение»; внутренние ID пакета и Android deep-link scheme сохранены для совместимости.
- Документация сборки, развертывания, безопасности и конфигурации обновлена под 0.2.0.

### Известные ограничения

- Для серверных функций нужны согласованные школьные настройки SSO, источник данных и, если нужен push, Firebase.
- Геометрия навигации требует проверки с утверждёнными планами; автотесты связности не сертифицируют эвакуационные маршруты.
- Перед подключением настоящих данных учеников необходимы согласование с администрацией школы и проверка инфраструктуры.
- Выпускной APK считается готовым только после успешной Android release-сборки и проверки артефакта.
