# «Поколение» — примечания о локальных уведомлениях

Исправлено:
- раньше планировался только ближайший урок текущего дня;
- теперь планируются уведомления на 7 календарных дней;
- перед повторным планированием старые уведомления очищаются;
- создан отдельный Android notification channel;
- запрашивается POST_NOTIFICATIONS на Android 13+;
- расписание использует Europe/Moscow, то есть время школы в Краснодаре;
- добавлены Android receivers для сохранения запланированных уведомлений после перезагрузки устройства;
- синхронизация расписания сразу перепланирует уведомления;
- ошибки уведомлений не ломают экран расписания.

Напоминание приходит за 5 минут до начала урока.
