# «Поколение» — релиз 0.2.0

**Версия приложения:** 0.2.0  
**Android version code:** 2  
**Дата подготовки:** 18 октября 2026

## Состав выпуска

- Офлайн-карта школы на трёх этажах, поиск кабинетов и построение маршрутов.
- Локальное расписание, выбор учебных групп, ДОПы и напоминания.
- Экран объявлений и школьный портал с правами по ролям.
- Серверная API-интеграция на FastAPI, SQLite, OIDC SSO и опциональные Firebase push-уведомления.
- JSON-файл или HTTPS API как настраиваемый источник справочных данных.
- Общешкольные уведомления с просмотром истории доставки и отменой ожидающей рассылки.
- Bootstrap первого директора и SSO-привязка через конфигурацию сервера.
- Проверки прав на общешкольную рассылку и сценарии отмены.
- Пользовательский брендинг «Поколение» во Flutter и web-оболочке.
- Обновлённые проверки безопасности и документация разработчика.

## Проверка перед публикацией

- [ ] `flutter pub get`
- [ ] `flutter analyze`
- [ ] `flutter test`
- [ ] `python backend/security_check.py`
- [ ] `python -m unittest discover -s backend/tests -v`
- [ ] `flutter build apk --release`
- [ ] Установить APK на Android-устройство и проверить запуск, карту, расписание, настройки и возврат из портала.
- [ ] Если включён сервер: проверить только на тестовых аккаунтах, HTTPS, вход/выход, роли, журнал аудита, импорт данных и уведомления.
- [ ] Подтвердить sha256 и размер фактического APK после сборки.
- [ ] Не публиковать APK с тестовыми секретами, неутверждёнными персональными данными или незаполненной производственной конфигурацией.

## Сборка

```powershell
flutter pub get
flutter test
flutter analyze
flutter build apk --release
```

Артефакт: `build/app/outputs/flutter-apk/app-release.apk`. Workflow CI загружает APK как `navigator-release-apk` с ограниченным сроком хранения.

## Примечание

Документ описывает исходный код и ожидаемую конфигурацию выпуска. Он не является заявлением об успешности сборки: фактический результат должен подтверждаться зелёным CI job и проверенным APK-артефактом.
