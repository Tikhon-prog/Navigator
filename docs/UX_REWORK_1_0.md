# «Поколение» — заметки о переработке интерфейса

- Нижняя навигация сокращена до: Карта / Расписание / ДОПы / Ещё.
- Карта стала главным экраном приложения; отдельной вкладки «Маршрут» нет.
- На телефоне выбор начала маршрута и этажа доступен прямо над картой.
- Начальная точка (кабинет/место) сохраняется локально на устройстве.
- Последние выбранные места сохраняются локально и доступны быстрыми кнопками.
- Поиск ранжирует точное совпадение номера выше остальных совпадений.
- На карте появился компактный блок активного маршрута с быстрым открытием/сбросом.
- Выбор места больше не использует непонятную кнопку только с иконкой.
- Диалоги редактирования имени и класса вынесены в отдельный Stateful-виджет с собственным lifecycle контроллера.
- Выбор роли администратора сделан расширяемым и прокручиваемым, чтобы не получать overflow на узком экране.
- Версия в интерфейсе приведена к 1.0.0.
- Gradle 8.14, AGP 8.11.1, Kotlin 2.2.20 и JVM target 21 синхронизированы.
