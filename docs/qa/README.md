# QA материалы Navigator

Эта папка содержит только документы аудита проекта и не подключается как Flutter asset.

Основные координаты и маршруты должны сверяться с исходными картами и файлами координат. Визуальные QA-изображения старого набора сюда не включены, чтобы не создавать ложное впечатление, что неполный набор точек является эталонным.
