# Navigator

Школьный навигатор для школы «Поколение».

Версия приложения: 1.0.0.

Основные части:
- Flutter/Android клиент;
- офлайн-карты и маршрутизация;
- расписание;
- индивидуальный выбор групп по предметам;
- локальные уведомления;
- админ-панель;
- локальная защита и аудит;
- заготовка backend/Yandex Cloud.
